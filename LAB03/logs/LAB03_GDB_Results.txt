BUG 1: ARRAY OUT OF BOUNDS
----------------------------------------

Function: process_data()

GDB Breakpoint:
break process_data

Observed:
len = 5
i = 5
sum = 150

Problem:
Loop condition i <= len accesses data[5]
while the array only contains 5 elements.

Fix:
Change i <= len to i < len.

----------------------------------------
BUG 2: USE AFTER FREE
----------------------------------------

Function: create_message()

GDB Breakpoint:
break create_message

Observed:
Buffer contains "Hello Embedded Linux"
before free().

After free(), the returned pointer refers
to memory that is no longer valid.

Fix:
Remove free(buf) from create_message().
Release memory in main() after using it.

----------------------------------------
BUG 3: INTEGER OVERFLOW

GDB Breakpoint:

Fix:
Use long long for the multiplication result.
